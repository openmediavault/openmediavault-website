The following changes were made:

**openmediavault 1.16**

- Restart cron daemon after changing system time.
- Mantis 0001282: OMV.form.plugin.LinkedFields is not working in some special use cases.
- Mantis 0001283: Recreate /var/cache/openmediavault/packages when file is missing instead of causing error.

**openmediavault 1.15**

- Update locales.
- Fix various ExtJS issues.
- Mantis 0001277: Set default language in WebUI to english.
- Mantis 0001279: Client field for NFS exports must not be forced.

**openmediavault-shairport 1.4**

- Improve package postrm script.

**openmediavault-usbbackup 1.3**

- Mantis 0001284: Use OMVFilesystems backend to support additional filesystems.
