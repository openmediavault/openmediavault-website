The following changes were made:

**openmediavault 2.1.6**

- Update locales.
- Improve config scripts.
- Fix an issue with the SSL and SSH certificate config scripts.
- Update the S.M.A.R.T. attribute descriptions.
- Send an email to the user if the account is used to log in to the control panel the first time via web browser. Please note, if an email can’t be delivered to an user, e.g. because of a missing email address, the email is redirected to the administrator account.
