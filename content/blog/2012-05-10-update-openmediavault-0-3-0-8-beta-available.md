**openmediavault 0.3.0.8**

- Fix broken user WebGUI.
- Do not use PHP_FCGI_CHILDREN. As a result this reduces the number of PHP processes.
- Mantis 0000394: Add more FTP SSL/TLS options.

Please update your system via ‘System > Update Manager’ in the OpenMediaVault WebGUI. Please reload the WebGUI to let the changes installed by the update take effect.
