**openmediavault 5.5.13**

- Update locales.
- Fixed bug in quota deployment on XFS filesystems.
- Issue #829: Show the listing of directory entries to which the anonymous user normally has no access permissions.
- Fixed some bugs in the UDEV rules file that address the problem of some USB PATA/SATA bridge controllers that they do not pass on the serial number of the attached disks.
- Convert ‘\r\n’ and ‘\r’ to ‘\n’ in RPC ‘Exec::getOutput’.
