**openmediavault 6.0.17**

- Display a hint on the performance statistic pages when the system monitoring is disabled.
- Disable MX lookup by default when sending emails. This can be enabled by setting the environment variable OMV_POSTFIX_MAIN_RELAYHOST_MXLOOKUP_ENABLE to ‘yes’.
- Issue #1236: Reduce CPU utilization on login page.
