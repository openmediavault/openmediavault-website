**openmediavault 6.6.0**

- Various improvements.
- Do not forward error to UI from SMART device enumeration.
- Fix bug in NFS configuration.
- Limit width of page body to 1900px. The page content will be centered for greater browser window sizes.
- Issue #1579: Add NetBIOS knob to SMB settings. This replaces the `OMV_SAMBA_NMBD_ENABLE` environment variable. Enable this to add support for name resolution and network discovery of legacy systems.
