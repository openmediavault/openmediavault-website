## THIS IS ONLY FOR PREVIEW AND TESTING.

Today an [ISO image for AMD64 platforms](https://sourceforge.net/projects/openmediavault/files/6.0/) has been released. This is an early preview, but fully functional. Please do not use it in production environments. Please note that right at the moment new package versions will not take care about configuration migration.

You can also install OMV6 on every Debian 11 system according to [this forum post](https://forum.openmediavault.org/index.php?thread/39490-install-omv6-on-debian-11-bullseye/). Alternatively you can use [Vagrant](https://github.com/openmediavault/openmediavault/tree/master/vagrant) to setup a test system.

If you find any bugs, please open a new issue in the [bugtracker](https://github.com/openmediavault/openmediavault/issues/new/choose).
