**openmediavault 8.5.11**

- Remove obsolete rsyslog configuration files.
- Set explicit file permissions in various Salt states. Thanks to Ma Xiaohan.

**openmediavault-diskstats 8.0.2**

- Set explicit file permissions for the collectd configuration file. Thanks to Ma Xiaohan.

**openmediavault-k8s 8.2.7**

- Set explicit directory permissions for the K3S configuration and manifest directories.
- Use K3S v1.35.9+k3s1 on new installations. Existing installations won’t be upgraded automatically.

**openmediavault-nut 8.0.7**

- Set explicit file permissions for the collectd configuration file. Thanks to Ma Xiaohan.

**openmediavault-photoprism 8.0.4**

- Set explicit file permissions for the appdata directories.
