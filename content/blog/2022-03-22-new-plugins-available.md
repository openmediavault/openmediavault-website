Today four new plugins have arrived in the OMV6 package repository. All of them are based on container technology, but without having to struggle with docker-compose files in Yacht or Portainer. The plugins can be configured as usual via the openmediavault Workbench and the deployment is done on a simple click.

The following plugins are now available:

- ownTone – DAAP (iTunes), MPD (Music Player Daemon) and RSP (Roku) media server
- File Browser – File managing interface
- PhotoPrism – AI-powered app for browsing, organizing & sharing your photo collection
- WeTTY – Terminal access in browser over HTTP/HTTPS
