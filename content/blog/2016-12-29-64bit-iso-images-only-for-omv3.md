---
title: "64bit ISO images only for OMV3"
date: 2016-12-29T12:24:30
slug: "64bit-iso-images-only-for-omv3"
categories: ["News"]
---

Starting today there will be only [64bit ISO images for OMV3](https://sourceforge.net/projects/openmediavault/files/3.0beta/) to download. If you still need a 32bit installation, then use the Debian 32bit [netinstall ISO image](https://www.debian.org/CD/netinst/) and install [OMV3 manually](http://forum.openmediavault.org/index.php/Thread/16833-Install-OMV3-on-Debian-Jessie/).
