The following changes were made:

**openmediavault 1.2**

- Update locales.
- Improve OMVHtmlPageAbstract::scanFiles() method to improve page loading speed.
- Drop TCP wrapper support via WebGUI ‘System | Network | Hosts’ because this is no longer supported by most applications. Use iptables instead.
- Mantis 0001194: Device “bonding_masters” does not exist.

**openmediavault-route 1.1**

- Update locales.
- Mantis 0001203: Can only have one static route.
