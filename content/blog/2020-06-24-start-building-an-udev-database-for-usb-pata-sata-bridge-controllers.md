The OMV project started to build an [UDEV rules database](https://github.com/openmediavault/openmediavault/pull/746) for faulty USB PATA/SATA bridge controllers that do not pass on the serial number correctly. Please help to populate this database, so OMV can ship it out-of-the-box and help other users to do not run into the problem that OMV doesn’t display all connected devices.
