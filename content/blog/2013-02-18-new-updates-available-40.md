The following changes has been done:

**openmediavault 0.4.23**

- Update locales.
- Improve config scripts (to fix trap issue).
- Harden rsync cron scripts. Check if destination storage device is mounted before running the script.
- Mantis 0000722: Stopped Rsync jobs still run in background.

**openmediavault-clamav 0.4.5**

- Improve config scripts (to fix trap issue).

**openmediavault-usbbackup 0.4.3**

- Update locales.
- Improve config scripts (to fix trap issue).

Please update your system via ‘System > Update Manager’ in the OpenMediaVault WebGUI. Please reload the WebGUI to let the changes installed by the update take effect.
