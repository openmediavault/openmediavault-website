The [openmediavault-k8s-recipes](https://github.com/openmediavault/openmediavault-k8s-recipes) GitHub repository has been created to contain the K8s recipes that can be consumed by the openmediavault-k8s plugin. I hope for active help from the community to fill this recipe collection with many templates of popular containerized applications. Anyone who would like to contribute should simply submit a PR [here](https://github.com/openmediavault/openmediavault-k8s-recipes/pulls?q=is%3Apr+is%3Aopen+sort%3Aupdated-desc).

Check the [README](https://github.com/openmediavault/openmediavault-k8s-recipes/blob/main/README.md) for the rules of the recipes. You might also check out the [K3s documentation](https://docs.k3s.io/helm) how to use Helm charts in your recipes. Use the already [existing recipes](https://github.com/openmediavault/openmediavault-k8s-recipes/tree/main/recipes) as templates.
