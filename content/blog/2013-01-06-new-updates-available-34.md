The following changes has been done:

**openmediavault (0.4.12)**

- Add Galician WebGUI language support.
- Update locales.
- Reconfigure smartmontools configuration if email notification settings has been modified.
- Make gateway field in the bond interface configuration dialogs optional.
- Send emails from user root to the primary email recipient.
- Add generic support to get S.M.A.R.T. attributes from USB devices.

**openmediavault-clamav (0.4.3)**
 **openmediavault-forkeddaapd (0.4.1)**
 **openmediavault-iscsitarget (0.4.2)**
 **openmediavault-ldap (0.4.1)**
 **openmediavault-lvm2 (0.4.2)**
 **openmediavault-netatalk (0.4.1)**
 **openmediavault-route (0.4.1)**

- Update locales.

Thanks to all translators for doing a great job.

Please update your system via ‘System > Update Manager’ in the OpenMediaVault WebGUI. Please reload the WebGUI to let the changes installed by the update take effect.
