Today i am happy to announce the release of OpenMediaVault version 2.1 ([Stone burner](http://dune.wikia.com/wiki/Stone_burner)).

A big thank you goes to all [translators](http://wiki.openmediavault.org/index.php?title=Contributors#Translators) and forum [moderators](http://wiki.openmediavault.org/index.php?title=Contributors#Forum) for their contributions and support.

The main features at a glance:

- Using Sencha ExtJS 5.1.1 framework for the WebGUI
- Add a new dashboard and widgets
- Many internal improvements and bugfixes
- Improved the internal network interface backend
- Add Wi-Fi support. Only WPA & WPA2 is supported
- Add VLAN support
- The network interface configuration page has been modified. Now only the configuration values are displayed. Use the dashboard widget to show the state of all network interfaces.
- The public key of the user must now be specified in the RFC 4716 SSH public key file format. It is possible to add multiple keys.
- Option to turn off the collection of system performance statistics.
- Use the browser local storage to store the WebGUI state (e.g. displayed grid columns, column width, …) instead of cookies.

The whole changelog for 2.1 can be viewed [here](http://sourceforge.net/p/openmediavault/code/HEAD/tree/trunk/deb/openmediavault/debian/changelog).

Support is available through the forum: [FAQ](http://forums.openmediavault.org/index.php/Thread/5594-OpenMediaVault-FAQ/), [Upgrade guide](http://forums.openmediavault.org/index.php/Thread/10049-Upgrade-to-OMV-2-x/) to 2.x and the general [guide section](http://forums.openmediavault.org/index.php/Board/29-Guides/).

The 32 and 64 bit ISO images can be downloaded [here](http://sourceforge.net/projects/openmediavault/files/2.1/).
