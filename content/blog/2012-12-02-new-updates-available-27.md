The following changes has been done:

**openmediavault 0.3.7**

- Add omv-dist-upgrade command to easily upgrade to the latest release version.
- Mantis 0000660: Cannot delete SSL certs in WebGUI.
- Mantis 0000662: Physical Drive – Advanced Power Management – Value 255.

**openmediavault 0.4.6**

- Update locales.
- Mantis 0000660: Cannot delete SSL certs in WebGUI.
- Mantis 0000662: Physical Drive – Advanced Power Management – Value 255.

Please update your system via ‘System > Update Manager’ in the OpenMediaVault WebGUI. Please reload the WebGUI to let the changes installed by the update take effect.
