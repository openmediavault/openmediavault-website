Today a MinIO based high-performance, S3 compatible object storage plugin has been released. Please note that this plugin, in addition to the [previously released plugins](/blog/2022/03/new-plugins-available/), breaks new ground by using container technology. Because of that please do not use them on production systems and only for testing. If you have found a bug, please file a report in the [bugtracker](https://github.com/openmediavault/openmediavault/issues/new/choose).

Please note that some of the plugins that are based on container technology are not available on all platforms. You will find the supported architectures in the plugin description.
