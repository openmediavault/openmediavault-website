I have uploaded the iscsi-target plugin here. It is not available via the package repository, thus you have to download it manually [here](http://packages.openmediavault.org/public/pool/main/o/openmediavault-iscsitarget/). Install it via dpkg, but note that there are huge dependencies because the kernel module has to be build from source (there is no seperate kernel-module package like in Debian Lenny).
