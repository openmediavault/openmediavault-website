The following changes were made:

**openmediavault 2.0.11**

- Update locales.
- Use ‘deadline’ I/O scheduler for non-rotating devices.
- Mantis 0001342: Unable to save firewall rules.
- Mantis 0001344: Add support to mount ISO9660 file systems. Only works with kernel (>= 3.16) and util-linux (>= 2.25.2).

Use the WebGUI or the omv-update CLI command to update your system.
