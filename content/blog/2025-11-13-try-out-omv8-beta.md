> [!CAUTION]
> - OMV8 is in beta phase right now. You can give it a try, but you should not use it on production systems.
> - The only supported platforms are AMD64 and ARM64.
> - If there are database changes, there will be no automatic migrations between 8.0-x versions.

Please check out the [forum](https://forum.openmediavault.org/index.php?thread/57611-install-omv8-on-debian-13-trixie/) or [documentation](https://docs.openmediavault.org/en/8.x/installation/on_debian.html) how to install OMV8 (Synchrony) on an existing Debian 13 (Trixie) system.

Please file bug reports on the [project GitHub page](https://github.com/openmediavault/openmediavault/issues/new?template=bug_report.md).
