Today the LVM2 plugin has been released. It will allow you to create and administrate your logical volume setup via the WebGUI. Administration activities that are not supported by the WebGUI should be done via CLI. Snapshot support will be implemented after OpenMediaVault 0.3 has been released.

openmediavault 0.2.6.8

\* Various improvements and bug fixes
\* Mantis 0000355: cant list Physical Disks; json_encode(): Invalid UTF-8 sequence in argument

openmediavault-lvm2 0.1

\* Initial release

Please update your system via ‘System > Update Manager’ in the OpenMediaVault WebGUI. Please reload the WebGUI to let the changes installed by the update take effect.
