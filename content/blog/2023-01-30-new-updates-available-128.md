**openmediavault 6.2.0**

- Relocate FTP service into a separate plugin. Please install the plugin if you are using the service. The configuration will be migrated.

**openmediavault-ftp 6.0**

- Initial release.

If you have enabled the FTP service in openmediavault < 6.2.0, please install the openmediavault-ftp plugin after the system has be upgraded. The FTP service configuration will be migrated.
