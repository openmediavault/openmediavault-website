The following changes were made:

**openmediavault 2.0.14**

- Update locales.
- Various improvements.
- Add temporary workaround to fix rendering bug in Chrome 43. See https://code.google.com/p/chromium/issues/detail?id=489875.
- Add support to create/import SSL certificates. This feature can be used by plugins.
- Improve ShareMgmt::setFileACL RPC to support a large number of users/groups.
