The following changes has been done:

**openmediavault 0.3.5**

- Improve code to assign hostname.
- Fix bug in the configuration init/sync script.
- Fix bug when deleting a shared folder recursively. The check to prevent the deletion of a shared folder that is a sub-directory of another one was erroneous.
- Mantis 0000644: Hostname is not updated.

**openmediavault 0.4.4**

- Update locales.
- Improve code to assign hostname.
- Fix bug in the configuration init/sync script.
- Fix bug when deleting a shared folder recursively. The check to prevent the deletion of a shared folder that is a sub-directory of another one was erroneous.
- Mantis 0000644: Hostname is not updated.

Please update your system via ‘System > Update Manager’ in the OpenMediaVault WebGUI. Please reload the WebGUI to let the changes installed by the update take effect.
