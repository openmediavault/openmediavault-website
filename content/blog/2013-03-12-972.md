The following changes has been done:

**openmediavault 0.4.26**

- Set default key size in the SSL certificate property dialog to 2048b.
- Various cosmetic improvements in WebGUI.

**openmediavault-clamav 0.4.7**

- Various cosmetic improvements in WebGUI.

**openmediavault-usbbackup 0.4.6**

- Update locales.
- Display if job is running in the job list (column ‘Running’).
- Add ability to backup from external to shared folder and vice verse.
- *!!! Attention !!! Now only the shared folder content is syncronized to the external storage.*

Please update your system via ‘System > Update Manager’ in the OpenMediaVault WebGUI. Please reload the WebGUI to let the changes installed by the update take effect.
