**openmediavault 6.4.8**

- Ensure the .snapshot directory exists when creating a scheduled snapshot of a shared folder.
- Disable SSH socket activation which is activated by default on several Debian derivatives.
- Add option `--append-dirty` to `omv-salt deploy run` to append states that are marked as dirty.

**openmediavault-ftp 6.0.2**

- Disable socket activation.
