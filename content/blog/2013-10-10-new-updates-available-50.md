The following changes were made:

**openmediavault 0.5.12**

- Update locales.
- Improve interface bonding RPC.
- Adapt WebGUI code to Sencha ExtJS 4.2.2.
- Mantis 0000857: Cant disable HDD write cache.

**openmediavault 0.5.13**

- Mantis 0000865: Allow entering a hostname/FQDN under System Logs -> Settings -> Host.
- Mantis 0000866: Device ‘ip6tnl0’ not supported.

**openmediavault-lvm2 0.5.2**

- Update locales.
- Mantis 0000859: Parent tab will not be refreshed after delete of child.

Please update your system via ‘System > Update Manager’ in the OpenMediaVault WebGUI. Please reload the WebGUI to let the changes installed by the update take effect.
