**openmediavault 5.6.3**

- Install security updates automatically. This can be disabled via the OMV_CRONAPT_SECURITY_UPGRADES_ENABLED environment variable.
- Send an email to the administrator if the system needs to be rebooted to complete a package upgrade.
- Rebuild SSH authorized keys even if the last public key of a user has been deleted.
- Replace omv-update by omv-upgrade.
