The following changes has been done:

**openmediavault 0.4.18**

- Update locales.
- Enable ‘Close’ button in ExecCmdDialog if the ‘Stop’ RPC fails.
- Use udev to retrieve various device informations.
- Prohibit various characters in comments.
- Fix bug in rsync script.

Please update your system via ‘System > Update Manager’ in the OpenMediaVault WebGUI. Please reload the WebGUI to let the changes installed by the update take effect.
