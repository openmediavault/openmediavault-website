The system can be enhanced via plugins. These plugins are installed on the system and have a UI extension that simplifies the configuration of the software/service.

The following plugins are available:

{{< cards >}}
{{< card >}}
- 2fa-totp – Two-Factor Authentication TOTP (Time-based One-Time Password)
- 2fa-emailotp - Two-Factor Authentication Email OTP (One-Time Password)
- clamav – Antivirus
- owntone – DAAP/MPD/RSP media server
- lvm2 – LVM management
- nut – Network UPS Tools
- shairport – AirPlay/RAOP receiver
- usbbackup – USB autobackup
- filebrowser – File managing interface
- photoprism – AI-powered app for browsing, organizing & sharing your photo collection
- wetty – Terminal access in browser over HTTP/HTTPS
- onedrive – Synchronizing a shared folder with Microsoft OneDrive cloud storage
- k8s – The Kubernetes plugin based on K3s with a [curated list of applications](https://github.com/openmediavault/openmediavault-k8s-recipes)
- bcache – Use an SSD as a read/write cache for another block device
- […](https://github.com/openmediavault/openmediavault/tree/master/deb)
